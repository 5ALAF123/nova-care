## 📖 About

This project is a modern hospital website designed with a strong focus on user experience, accessibility, and professional healthcare branding.

The website allows visitors to explore hospital departments, discover doctors and medical services, learn more about the hospital, and access appointment and contact information.

The project was built as a portfolio piece to demonstrate modern web development and UI/UX skills.

## ✨ Features

- 🏠 Modern healthcare landing page
- 🏥 Hospital overview
- 🩺 Medical departments
- 👨‍⚕️ Doctors directory
- 📅 Appointment booking interface
- 💊 Medical services
- 📍 Location and contact information
- 📞 Contact section
- 🚑 Emergency information
- 📱 Fully responsive design
- ✨ Smooth animations and transitions
- 🎨 Professional healthcare-focused UI

## 🩺 Patient Experience

The website is structured around a simple patient journey:

1. Discover the hospital
2. Explore medical departments
3. Find a suitable doctor
4. Learn about available medical services
5. Book an appointment
6. Contact the hospital

## 🎨 Design
